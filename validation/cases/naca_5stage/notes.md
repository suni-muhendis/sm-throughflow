# naca_5stage: design report not found (search log, 2026-10-01)

Target: Sandercock, D. M.; Kovach, K.; Lieblein, S.: Experimental
Investigation of a Five-Stage Axial-Flow Research Compressor with Transonic
Rotors in All Stages. I - Compressor Design. NACA RM E54F24, 1954 (UNT MOCAT
lists 35 pp. + 2 leaves, dated September 8, 1954). It holds the chord,
solidity, stagger and t/c data, which the open Parts II-IV do not contain.
No blade geometry was transcribed; this folder holds only this note.

## Searched

1. NTRS API (`ntrs.nasa.gov/api/citations/search`):
   - `q=five-stage transonic rotors in all stages`, `q=transonic rotors in
     all stages`, `q=five-stage compressor design transonic rotors`: only
     Parts II (19930088375, RM E54G01), III (19930089600, RM E56G24), IV
     (19930089563, RM E57B12) and the distortion report 19930090098
     (RM E57J17). No Part I.
   - `q=E54F24` and `q=RM E54F24`: only 19930088321, which is NACA
     RM E54F24a (Dugan, "Effect of design over-all compressor pressure
     ratio division on two-spool turbojet-engine performance and
     geometry"), a different report with the same base number.
   - `author=Sandercock`, `q=Sandercock Kovach Lieblein`,
     `q=Sandercock 1954 compressor`: nothing for Part I.
2. UNT Digital Library: the site search pages return a bot-validation page
   to scripted access (WebFetch and curl). A domain-restricted web search
   (`digital.library.unt.edu`) finds Part III (ark:/67531/metadc63178) and
   the eight-stage and inlet-stage reports, but no Part I. UNT MOCAT
   catalogue records (mocat.library.unt.edu/catalog/771-5233, 771-5234,
   771-5241) appear in web search for the title; MOCAT returns HTTP 403 to
   scripted access, so it could not be checked whether a digital copy is
   linked. MOCAT is a catalogue of the print holdings; the record found in
   search results gives the page count above, not a scan.
3. Cranfield AERADE (reports.aerade.cranfield.ac.uk): discover search
   "five-stage transonic rotors in all stages" gives only unrelated
   results; author search "Sandercock" gives no results.
4. HathiTrust catalogue: HTTP 403 to scripted access; not searchable from
   here.
5. DTIC: a web search hit AD0028969 turned out to be Lewis, Schwenk and
   Serovy, transonic DCA rotor (not this report); the DTIC PDF and
   citation pages block scripted access.
6. General web search on title, report number, and authors: only citations
   (e.g. secondary literature) and catalogue entries; no open PDF.
7. Also checked the open parts for geometry: RM E54G01 (Part II) text has
   no chord/solidity/stagger table; RM E57J17 (downloaded to the validation
   folder as RM-E57J17_5stg_distortion.pdf) has no blade-geometry table.
   RM E57B12 (Part IV) Fig. 10 gives rotor and stator camber angles only
   (figure, not digitized here).

## Outcome

No open copy of RM E54F24 was found. Ways that remain: ask the UNT Digital
Library / NASA (NTRS help desk) for a scan, check HathiTrust interactively
in a browser, or a library interlibrary loan of the NACA RM. The ASME paper
Kovach and Sandercock, J. Eng. Power 83 (1961), is not open access.
