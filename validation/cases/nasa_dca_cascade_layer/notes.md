# NASA CR-185118 suction surface at −8.5 degrees incidence

Table 13 contains measured static-pressure coefficients and the associated
inviscid edge speeds. Table 15 contains shear-layer parameters derived
from velocity traverses. The S rows refer to the suction surface. The
authors infer the first two suction-side momentum-thickness Reynolds
numbers and shape factors using a Falkner–Skan fit. The spline fit is
available from 30.1% chord. The two reductions differ at that station.

Volume I Appendix A gives a chord of 228.6 mm between edge-circle centres
and a suction arc radius of 189.1 mm. Printed page 148 describes the spline
fit passing a laminar-separation shape factor of 3.5 near 31.9% chord. This
is a profile-based estimate of separation, not a directly measured
wall-shear zero. The model comparison preserves that distinction.

The reference calculation starts at 10.4% chord using the authors' first
Falkner–Skan reduction and uses only the pressure-tap edge history as
forcing. A second run starts from the authors' fit at 19.7% to check
sensitivity to the supplied initial layer. It does not use 19.7% as a
comparison point in that run. The far-wake data for this same cascade are
stored in the separate NASA DCA wake case.
