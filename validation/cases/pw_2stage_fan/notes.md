Sources: NASA CR-120859 (design, P&W, 1972) and NASA TM X-3076 (NASA Lewis test, 1974).
All PDF page numbers are 1-based PDF indices.

**Recommended source for section geometry:** the TM X-3076 reprints (Tables XVI-XIX) for the
English block; they are clean typeset copies of CR-120859 Tables XVII-XX. The CR scans are poor;
their `?` cells were resolved against the reprint where the reprint is legible, and the value
written before `?` in the CR file is then the reprint value. Unmarked CR cells agree with the
reprint. The Metric block exists only in the CR scan.

## Conventions (as stated in CR-120859 Appendix F symbols, PDF pp. 131-134)

- Sections lie on **conical surfaces** approximating streamsurfaces; table headers give inlet/exit
  root and tip diameters of each row's cones.
- Metal angle beta*: "metal angle, on conical surface, between tangent to mean camber line and
  meridional direction at leading and trailing edge". Rows printed: beta'*ss1 (suction-surface
  angle at LE) and beta'*1 for rotors; beta*ss and beta*2 for stators (subscripts partly
  illegible in the CR scan, clear in TM X: stator rows read "beta*ss2"?/"beta*2"). Only inlet
  angles are tabulated; exit metal angle follows from camber.
- phi = camber, beta'*1 - beta'*2 (rotors), beta*2 - beta*3 (stators); phi_E = camber on the
  "unwrapped" cone including the epse angle E (Fig. 23); phi_f, phi_Ef = front camber (to the
  transition point), two definitions likewise.
- c = aerodynamic chord on the flow surface; c_f = front chord; a/c = location of max camber
  elevation; `% c to max t`; RLE = RTE = edge radii; sigma = solidity.
- The second-to-last row has an unclear symbol (printed like a small epsilon/gamma). Its values
  (rotor 1: +20.3 at hub to -12.9 at tip) are not stagger. Candidates from the symbol list:
  "gamma - blade chord angle ... measured in a plane parallel to z-axis" or a twist/epse angle.
  Left unresolved; labelled "ε (glyph unclear)".
- Aerodynamic tables: B = absolute flow angle, B' = relative, measured from meridional/axial;
  rotor relative tangential velocity VO' is negative (VO' = VO - U); INCS/INCM incidence to
  suction surface / mean line; station numbers 7-14 in the overall lines.
- Flowpath z: inches (meters) from rotor 1 hub leading edge (station 4 hub z = 0.0).

## Cells marked `?` and inconsistencies found

- Every CSV has had a full second read, cell by cell, against the page image (see each
  `source.json` note for the corrections). The complete list of `?` cells is in the appendix
  at the end of this file.
- SI aerodynamic tables: velocity-block cells that are faint, or whose glyph conflicts with the
  velocity-triangle identities (V, B, VO' = VO - U, V', B', and M'/M = V'/V), carry `?`
  (e.g. Table X 100 % flow VM-2 175.68?, Table XIV 3.15 % V-1/VM-1 208.98?). Where the glyph is
  legible but disagrees with the identity (Table X 41.45 % VM-2 printed 182.70, identity ~182.76;
  Table XIV 74.60 % B'-1 printed 1.0157, identity 1.0152; Table XVI 62.90 % B'-1 printed .7817,
  identity .7811) the printed reading is kept with `?`.
- CR Table X overall line: NCORR INLET is printed **122.60** (the leading 1 is missing in the
  print); Tables XII, XIV and XVI print 1122.60. Copied as printed.
- CR Table XVI (SI) 100 % flow INCM is printed **.087** rad, while English Table XV prints
  0.5 deg (= .009 rad); one of the two prints is a slip. Copied as printed.
- CR Table XIX metric: 22.70 % beta'*ss1 reads 0.890 but English 51.6 deg = 0.9006 rad;
  41.45 % sigma metric 1.78 vs English 1.77. Copied as read.
- CR Table XX span rows (scan nearly illegible) agree with the TM X Table XIX reprint where any
  digit is visible: 87 % flow 89.0/88.95/88.9 (an earlier reading 90.0 was wrong), 41.45 % 46.x.
- Header lines: CR Stator 1 (XVIII) and Stator 2 (XX) headers carry no tilt line; Stator 1
  inlet tip diameter is printed "29.67" without "Inches" in both CR and TM X.
- CR Table XX (stator 2): many cells have no reading at all (`?` alone); use TM X Table XIX.
- CR vs TM X differences that are real reading conflicts were resolved in favour of the clean
  TM X print and flagged `?` in the CR file (e.g. rotor 1 phiEf at 80.70 % flow: CR scan looked
  like 0.5, TM X 0.9 and metric .016; stator 1 t/c at 10.40 %: 0.0500).
- TM X Table XIX percent flow column 8 printed **51.35**; every other table has 51.85.
- CR Table III aspect ratio rotor 2: text layer 2.60, image and TM X 2.69.
- Flowpath Fig. 10 station 9 OD z = 8.82 in. while ID z = 9.20 (tip TE upstream of hub TE); as
  printed.
- Rotor 1 exit root diameter: CR/TM X Table header 14.91 in. (.378 m), whereas flowpath station 5
  ID is 14.84 in. (.377 m); stations are blade-edge points, the header is the cone definition.
- **Tip clearance values are not printed** in either report (TM X-3076 only says proximity
  probes monitored it). P&W test reports CR-134710/134717/134722 (not downloaded) may give them.
  A full search of the TM X-3076 text layer ("clearance", "station", "upstream", "downstream")
  found no clearance value and no further station axial positions beyond those now in
  `scalars.json` (station 6: 2.25 in. upstream of rotor 1; stations 7 and 8 halfway between
  rows; station 10 within 1/2 chord downstream of stator 2; stator 2 leading-edge probes at
  10/30/50/70/90 % span; support struts 14 in. upstream and 11 in. downstream). TM X-3076 Fig. 7
  (PDF p. 159) shows the plane positions only graphically (figure only, not digitized).
